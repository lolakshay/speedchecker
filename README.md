# 🚀 Internet Speed Analyzer  
### Smart Speed Test for Meet, Gaming & Streaming

A **dynamic web-based internet speed analyzer** with themed UI (Office, Gaming, Anime/Streaming) that evaluates real-world performance for video conferencing, gaming, and media streaming.

## ✨ Features

### ⚡ Real-Time Speed Testing
- Measures internet speed in **Mbps**
- Displays results instantly with visual feedback
- Retest functionality for continuous monitoring

### 🎨 Multi-Themed UI
Switch between different usage scenarios:
- 🏢 **Office Mode** → Google Meet / Zoom readiness
- 🎮 **Gaming Mode** → Gaming experience insights
- 🎬 **Anime/Streaming Mode** → Streaming performance analysis

### 🧠 Smart Analysis
Based on your speed, the app tells you:
- Can you attend **video calls smoothly**
- Is your internet good for **online gaming**
- Can you stream **HD / 4K content**

### 📊 Tier-Based Classification
Speed is categorized into:
- 🔴 Poor  
- 🟡 Average  
- 🟢 Good  
- 🔥 Excellent  

Each tier includes:
- Capabilities  
- Limitations  
- Dynamic feedback  

### 🎮 Interactive Easter Eggs
- Hidden gaming messages  
- Fun overlays & animations  
- Themed surprises  

### 📱 Fully Responsive
- Works on desktop, tablet, and mobile  
- Smooth UI transitions

## 📊 Speed Interpretation

### 🏢 Office / Meetings
- **< 2 Mbps** → Audio only / lag  
- **3–5 Mbps** → Basic video calls  
- **5–10 Mbps** → Stable HD calls  
- **25+ Mbps** → Smooth multitasking  

### 🎮 Gaming
- **< 5 Mbps** → Laggy  
- **5–20 Mbps** → Playable  
- **20–50 Mbps** → Smooth  
- **50+ Mbps** → Competitive ready  

### 🎬 Streaming
- **< 3 Mbps** → Low quality  
- **5 Mbps** → HD  
- **25 Mbps** → 4K  
- **50+ Mbps** → Ultra HD
